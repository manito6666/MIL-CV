Implementación de VPN tipo SSL

1. Objetivo

Instalación de una VPN en Windows Server utilizando el protocolo SSL y validación desde un equipo cliente. Incluye creación de certificado autofirmado, configuración del rol de VPN y verificación del acceso.

2. Pre-configuración

Se utilizó Host-Only en ambas máquinas virtuales para simplificar la configuración y asegurar un entorno controlado. Se asignaron IPs estáticas para evitar conflictos y facilitar la conexión.

3. Instalación del rol VPN Server SSL

Se instaló AD DS para gestión centralizada y autenticación, y luego el rol Remote Access (RAS) con la opción DirectAccess and VPN.

Comandos / pasos relevantes 
Net user Administrator [nueva_contraseña]
Instalar Remote Access -> VPN only
Seleccionar Role Services: DirectAccess and VPN (RAS)

4. Creación de certificado autofirmado

Se creó un certificado desde IIS Manager: Server Certificates → Create Self-Signed Certificate. Se asignó un nombre para identificarlo fácilmente.

Este certificado permite comunicaciones seguras vía SSL.

5. Configuración del rol de VPN y requerimientos

Se configuró RAS en modo VPN only. En Properties → Security → Certificate Binding se asoció el certificado SSL.

6. Validación con equipo cliente

Se importó el certificado en el cliente y se colocó en el almacén de "Entidades de certificación de confianza".

  • Permitir acceso al usuario en Active Directory (Dial-in → Allow Access).
  • Conexión mediante SSTP (puerto 443) desde Configuración VPN de Windows o comando rasdial.

7. Notas importantes

  • Verificar que ambas máquinas respondan al ping.
  • Revisar firewall y reglas para SSTP / ICMPv4.
  • Agregar nombre del certificado en el archivo hosts si no hay DNS local.

8. Conclusiones

El proyecto fue práctico y motivador, fomentó investigación autónoma y aprendizaje de certificados y criptografía. Permite comprender mejor seguridad web y VPN.
