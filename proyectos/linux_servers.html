Proyecto Final: Servidores Linux

Materia: Servicios Seguros de Internet - M6 - Proyecto Final

1. Introducción

Este proyecto tiene como objetivo la configuración y despliegue de dos servidores Linux plenamente funcionales, cada uno con servicios específicos que colaboran en conjunto para lograr un entorno robusto, seguro y automatizado...

2. Server 1

2.1 Instalar Apache

Arrancamos el servicio, instalamos Apache, MySQL y PHP, habilitamos SQL, configuramos WordPress y generamos certificados autofirmados.

2.2 Bind9 y dominios

Instalación de Bind9, configuración de zonas, resolución de nombres y pruebas con nslookup.

2.3 Server 1 Hardening de seguridad

Configuración de SSH, firewalld y SELinux para asegurar el servidor y restringir accesos.

3. Server 2

3.1 Instalar SNMP

Instalación y configuración de net-snmp para supervisión de red.

3.2 Descargar e instalar Zabbix

Instalación de Zabbix server y agentes, configuración de base de datos y panel web.

3.3 Instalación de Grafana y plugin de Zabbix

Instalación de Grafana, plugin Zabbix, configuración de dashboards, métricas y alertas.

3.4 Script de backups

Automatización de backups de logs y datos importantes entre los servidores usando SCP y cronjobs.

3.5 Hardening Server 2

Configuración de firewalld, SELinux y usuarios con roles distintos para asegurar el servidor de monitoreo.

4. Conclusión

El proyecto consolidó conocimientos en administración de servidores Linux, configuración de servicios web, monitoreo, seguridad y automatización. Aprendizaje práctico y profundo en Fedora Linux.
